# Morning

Do these in order. Every button name is exact.

## Before anything

1. **Settings → Backup → Export backup.**
2. Keep the file somewhere you can find it.

## Build the week

3. **Templates → New template → A week.**
4. Type the name in **Week name**.
5. Press **All days**.
6. Type `07:00` in the time box, the title in **What happens**, press Return.
7. Repeat step 6 for each block that is on every day: meals, reading, the evening one.
8. On the Monday column, press **Note** on the morning block.
9. Type each step into **Add a step** and press Return after each one.
10. On the Monday column, press **Note** on a meal block, type what to make.
11. Repeat step 10 for the other meals.
12. Press **Weekdays**.
13. Type a time, a title in **What happens**, press Return - once per weekday block.
14. On the Monday column, press **Key** on the two that matter most.
15. Press **Weekend**, then add the weekend blocks the same way.

## The rotation

16. Press the day switches you want: **M T W T F S S**. Each one turns on and off on its own.
17. Read the line under them: *Adds to Mon, Thu*. That is where the next block lands.
18. Type the time and the title, press Return.
19. The switches stay put. The next block in the same rotation is a title and Return.
20. For a single day, press **Only Wed** (it names whichever column you are on), then the switch you want.

## Finish the template

21. On the Sunday column, press the day type line, choose **Rest**.
22. Press **Save template**.

## Point the week at it

23. **Settings → Week → A template per weekday.**
24. Set all seven dropdowns to the week template.
25. **Settings → Sleep.** Set **Bedtime** to `23:00` and **Wake time** to `07:00`.

## North

26. **North.** Type one line in **The picture**, press **Keep it**.
27. Press **Compose**.
28. Fill **What**, **Why it matters**, **Who it makes you**, **What I do to deserve this**.
29. Press **Add another** for the second goal, then the third.
30. Press **Save**.

## The list

31. **Library → New list.** Name it, pick the unit, press **Save**.
32. Type `Title, 12 chapters` in the add box and press Return, once per item.

## Backup to GitHub

33. **Settings → Backup.** Fill **Repo** and **Token**.
34. Press **Save**.

## Start the day

35. **Today.** Press the week template's chip in **Templates** on the left.
36. Check the header says `0/n · 0 of 3 key`.

---

If something looks wrong: **Settings → Backup → Import backup**, and the file from step 1.
